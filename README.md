📊 Tableau Retail & Sales Analytics Dashboard | Data Technician Bootcamp
🚀 Project Overview
This project was completed as part of a Data Technician Bootcamp and focused on transforming retail and sales data into meaningful insights using Tableau. The project involved designing interactive dashboards, creating visual reports, and exploring business performance metrics to support data-driven decision-making.

Using Tableau's powerful visualization and analytics tools, I developed engaging dashboards that enabled users to explore sales performance, customer behavior, product trends, and regional insights through interactive filtering and dynamic visualizations.
